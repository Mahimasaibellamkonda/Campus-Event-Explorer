# Campus Event Explorer 

Campus Event Explorer is a responsive web development project that helps students discover and register for events happening on their college campus.

The project is built using **HTML, CSS, and basic JavaScript** without any backend or database.

##  Features

* View upcoming campus events
* Search events by name
* Filter events by category
* View event date, time, and venue
* Register for an event using a simple form
* Form validation using JavaScript
* Registration success message
* Responsive design for different screen sizes
* Dynamic event cards generated using JavaScript

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Dynamic content, search, filtering, modal, and form validation

##  How It Works

### 1. Event Data

Event information such as title, category, date, time, and venue is stored in a JavaScript array.

### 2. Dynamic Event Display

JavaScript reads the event data and dynamically creates event cards on the webpage.

### 3. Search

Users can enter an event name in the search box. JavaScript filters the available events based on the entered text.

### 4. Category Filter

Users can filter events using categories such as:

* Technical
* Cultural
* Sports
* Workshop

### 5. Registration

Clicking the **Register** button opens a registration form.

The form collects:

* Student Name
* Email Address

JavaScript checks whether the required fields are filled before displaying the registration success message.

##  How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Make sure `index.html`, `style.css`, and `script.js` are in the same folder.
4. Open `index.html` in any modern web browser.

No installation or additional software is required.
